한화에몽 MarketView 대시보드의 **서술형 콘텐츠만** 오늘 기준으로 갱신한다.
작업 대상 파일은 저장소 루트의 `index.html` 단일 파일이다.

## 컨텍스트
- 지수·원자재·환율·미국채 금리·중장기 종목 종가 등 **수치 데이터는 직전 단계(scripts/update-market-data.mjs)에서 이미 실측 갱신**되었다. 그 숫자(`val` `chg` `pct` `spark` `closes`)는 건드리지 않는다.
- 오늘 날짜는 시스템 기준(UTC) + 9시간 = KST. 미국장은 직전 거래일 종가 기준(휴장일 반영).

## 갱신할 것 (이것만)
1. **각 탭 상단 인사이트 문단** — `<div class="insight">` 7곳. 오늘 시장 상황·수급·이벤트에 맞춰 2~4줄로 다시 쓴다. **반드시 명사형 어미**로 끝맺는다(`…압박`, `…관건`, `…축소`, `…국면`). 종결형(`…한다/…이다/…했다`) 금지.
2. **홈 "오늘의 인사이트"** — `<div class="today">` 안의 `<p>`. 오늘 시장 상황을 3~5줄 서술형으로. (히어로 소개문 `<p class="hero-desc">` 은 고정 문구이므로 건드리지 않는다.)
3. **P2 증시 캘린더**(`var A=[...]`) — 이번 주~다음 주 확정 일정의 날짜·발표치·예상치. FOMC/BLS/한국은행/통계청 공식 캘린더 기준. 확정 안 된 항목은 기존 `mock`/`예시` 태그 유지.
4. **P3 글로벌 이슈·밸류체인·해외 IPO**(`var ISSUES=[...]`, `var CHAINS={...}`, `var KWHY={...}`, `var IPO=[...]`) — 최근 24~72시간 핵심 이슈로 갱신. IPO 파이프라인은 상장/신고 상태 변화 반영.
5. **P4 전일 수급**(P4 섹션 데이터) — 직전 거래일 KOSPI·KOSDAQ 주체별(외국인·기관·개인) 순매수/순매도 방향과 금액. 한국경제·머니투데이·인포스탁데일리·연합인포맥스 등 마감 기사 종합. 종목별 정량 순위가 확인 안 되면 기존값 유지 + `disc` 문구에 명시.
6. **P5 중장기 전망 코멘트·목표주가**(`var CONS=[...]`, `var MACRO=[...]`) — 공개 증권사 리포트·기사로 확인된 목표주가·투자의견만 갱신. 미확인 항목은 `mock` 유지.
7. **P6 리그테이블**(`var LT=[...]`) — 더벨/딜사이트 등 공개 누적 리그테이블로 확인되면 갱신. 미확인 시 유지.
8. **기준일자 문자열**과 각 섹션 `disc`(출처·기준일) 문구의 날짜.
9. **P1 지수 실측 교차검증** — `var IDX=[...]` 의 각 지수 `val`·`chg`·`pct` 를 WebSearch 로 직전 거래일 종가와 대조한다. Yahoo Finance 무료 API 는 아시아·유럽 지수(코스피·코스닥·니케이·상해·유로스톡스)의 최신 종가를 하루 이상 늦게 채우는 경우가 있어, 수치 단계(`update-market-data.mjs`)가 해당 지수를 건너뛰고 **전일 값이 그대로 남아 있을 수 있다**. 뉴스 실측과 `val` 이 0.3% 이상, 또는 `pct` 부호/자릿수가 다르면 뉴스 기준으로 `val`·`chg`·`pct` 및 `spark` 마지막 값을 정정한다.

## 절대 규칙
- **디자인·레이아웃·CSS·JS 함수·태그 구조는 절대 바꾸지 않는다.** 데이터 리터럴의 문자열/숫자 값과 인사이트 텍스트 노드만 수정.
- **`<p class="hero-desc">` 소개 문구는 고정.** 절대 수정하지 않는다.
- 새 탭·섹션·CSS 규칙·파일 추가 금지. 함수 시그니처 변경 금지.
- **확인 못 한 수치는 창작하지 않는다.** 기존 값과 `mock:true` / `예시` 태그를 그대로 둔다.
- 배열 길이·객체 키 구조를 바꾸지 않는다(요소 추가/삭제 금지, 값만 교체).
- 편집 후 파일이 `</html>` 로 끝나고 `<script>` 태그 짝이 맞는지 스스로 확인한다.

## 절차
1. `index.html` 읽기.
2. WebSearch/WebFetch 로 위 3~7 항목의 최신 정보 확인.
3. 확인된 것만 값 교체(Edit). 인사이트 문단 재작성.
4. 기준일자·disc 날짜 갱신.
5. `node scripts/validate-html.mjs` 실행해 통과하는지 확인. 실패하면 원인 수정.
6. 무엇을 갱신했고 무엇이 여전히 mock인지 3줄 이내로 출력.
